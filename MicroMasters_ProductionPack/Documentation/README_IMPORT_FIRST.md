# MicroMasters Production Pack 01 – Foundation

This ZIP starts the 5,000 asset production library.

Created in this package:
- Separate PNG assets for workers, buildings, UI, icons, VFX, backgrounds and props
- WAV SFX
- Economy/config/localization files
- Master asset index with exactly 5,000 planned asset records
- Unity folder structure and import guidance

Recommended Unity import:
- Texture Type: Sprite (2D and UI)
- Alpha Is Transparency: On
- Pixels Per Unit: 100
- Compression: Normal Quality for gameplay sprites, High Quality for UI
- Max Size: 512 for icons/workers, 1024–2048 for backgrounds
